## About me

I am a software engineer at **Meitech**, where I build the software that sits between industrial hardware and the people who operate it. My background is in mobile robots and embedded systems, and today most of my time goes into computer vision.

* Training and evaluating instance segmentation models, from dataset curation to deployment on the edge
* Writing C++ and Qt applications that talk to cameras, load cells and PLCs in real time
* Building simulators so that weighing and fieldbus software can be tested without the physical machine
* Learning advanced ROS 2 design patterns, CAN bus integration and real time vision

## What I work on

  <tr>
    <td width="50%" valign="top">
      <h3>Computer vision</h3>

    </td>
    <td width="50%" valign="top">
      <h3>Industrial weighing</h3>
      Software for multihead and dynamic weighing systems, load cell amplifier integration, and simulators that reproduce device protocols over serial ports, FastAPI and WebSocket.

  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>Industrial communication</h3>

    </td>
    <td width="50%" valign="top">
      <h3>Embedded Linux and HMI</h3>
      Torizon OS on Toradex modules, containerized applications, and operator interfaces built with Qt 6, React, Electron and Flutter.
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">

    </td>
    <td width="50%" valign="top">
